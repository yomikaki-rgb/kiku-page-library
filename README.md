# きくページ図書館

きくページとは別の、GitHub Pages だけで公開する図書館アプリです。先生が認識・編集済みの検索可能PDFを追加すると、生徒は本棚から選んで読み上げられます。図書館ではOCRをやり直しません。

## 最初の公開

1. ZIPを解凍し、その中身を入れた**新しいGitHubリポジトリ**を作ります。既存のきくページのリポジトリとは分けます。ZIPそのものをアップロードするだけでは公開できません。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` ブランチにファイルを保存すると、図書館が自動で公開されます。URLはリポジトリの **Settings → Pages** に表示されます。

## 本を追加

1. 元のきくページで資料を読み取り、必要な文字・読み順・読み方を編集します。
2. **保存 → 検索可能PDF** で保存します。
3. GitHubの図書館リポジトリを開き、`books` フォルダーにそのPDFをアップロードします。
4. GitHubの公開処理が終わると、PDFのファイル名が本棚に表示されます。`library.json` を手で編集する必要はありません。

きくページが保存した検索可能PDFには、紙面と読み上げ用の文字情報が含まれています。通常のPDFを追加すると、図書館で開く際に案内が表示され、OCRは始まりません。ブラウザ版GitHubでアップロードできるファイルは1件25 MiBまでです。

## 公開する資料

GitHub Pagesの図書館とPDFはインターネットに公開されます。公開の権利を確認した資料だけを`books`に入れてください。アプリを別にしても、資料への閲覧制限にはなりません。

この図書館ではPDFを端末に読み込み、読み上げは端末の音声機能を使います。生徒の編集内容は図書館に書き戻しません。
